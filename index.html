COMMON QUESTIONS / 03

FAQ.

Это настоящий сервис?

Нет. Это локальный фронтенд-макет для изучения дизайна. Он не подключён к серверам и не выполняет игровые функции.

Регистрация работает?

Окно входа здесь демонстрационное. Не вводи реальные пароли: для настоящей авторизации нужен защищённый сервер или сервис вроде Supabase.

Как запустить сайт?

Распакуй архив и открой index.html в браузере. Для редактирования открой папку в Visual Studio Code.
