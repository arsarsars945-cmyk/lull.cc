# lull.cc — UI concept

Это учебный фронтенд-макет сайта в тёмном игровом стиле. Он не является официальным сайтом и не подключён к игровым функциям.

## Как запустить
1. Распакуй ZIP в отдельную папку.
2. Открой `index.html` в браузере.
3. Чтобы редактировать код, открой папку в Visual Studio Code.

## Файлы
- `index.html` — содержимое страницы
- `style.css` — дизайн и адаптация под мобильные экраны
- `script.js` — интерактивное демо-окно и мобильное меню

## Важно
Окно аккаунта — только демонстрация. Оно ничего не отправляет и не сохраняет. Не вводи настоящие пароли. Для реальной регистрации потребуется безопасный backend/провайдер авторизации, например Supabase, с настройкой защиты и политик доступа.
